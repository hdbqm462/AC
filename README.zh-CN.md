## 🚀 最近的项目

### [Body Fat Calculator](https://apps.apple.com/)
一款用于记录体重、估算体脂率的 iOS 应用。

- 使用 **美国海军法（U.S. Navy method）** 计算体脂率
- 记录体重，并通过 HealthKit 同步到 **Apple 健康**
- 使用 **Xcode** 和 **Swift** 开发
- 已上架 App Store
